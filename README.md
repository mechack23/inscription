# Formulaire d'inscription Campus France 2026-2027

Formulaire en ligne de **HAYE AGENCY** pour collecter les informations des étudiants qui veulent étudier en France : parcours scolaire, niveau de langue, projet d'études, financement, logement, visa et documents.

## Fonctionnement

- L'étudiant remplit la fiche, répartie en 9 rubriques.
- À la validation, il envoie ses réponses à l'agence par WhatsApp ou par e-mail, ou les copie pour les coller dans la conversation.
- Aucune donnée n'est stockée sur un serveur.

## Technologies

HTML, CSS et JavaScript, dans un seul fichier `index.html`. Hébergement gratuit avec GitHub Pages.

## Modifier le formulaire

Les questions se trouvent dans la liste `S` du fichier `index.html`. Le numéro WhatsApp et l'e-mail de l'agence sont sur la ligne `const WA=...,MAIL=...`.
